# Georgian Cards · ქართული ბარათები

Интерактивная образовательная платформа для изучения грузинского языка, алфавита **Мхедрули (33 буквы)**, специфической фонетики (придыхательных и абруптивных согласных), живой лексики и пар антонимов.

## Масштаб базы контента (100% автономно)

- **33 буквы грузинского алфавита** с артикуляцией, 4-линейной строчной разметкой Мхедрули и прописью на Canvas.
- **165 двусторонних умных карточек** (ровно по **5 карточек на каждую из 33 букв**) по ключевым темам: *Еда, Город, Природа, Действия, Прилагательные, Эмоции, Транспорт, Быт*.
- **495 озвученных примеров предложений** (по 3 живых фразы с пословным разбором на каждой карточке).
- **24 минимальные фонетические пары** в тренажёре слуха (придыхательные, горловые, звонкие, свистящие и шипящие согласные).
- **813 локальных MP3-файлов** нейросетевой грузинской озвучки (`ka-GE`) и **275 реальных фотографий Грузии** в `assets/`.
- **Светлая и Тёмная темы (Glassmorphism + Motion Design):** обсидианово-сланцевая тёмная тема (`#0B0D12`) с полупрозрачными стеклянными панелями, шафраново-янтарными акцентами (`#F59E0B` / `#FBBF24`), изумрудным прогрессом (`#10B981`), кинематографичной сменой темы **Circular Reveal** (`View Transitions API`), интерактивным **Spotlight & 3D Tilt** и каскадными анимациями.

## Быстрый запуск

1. **Прямое открытие:** откройте файл `index.html` в любом современном браузере.
2. **Локальный веб-сервер:**
   ```bash
   python3 -m http.server 8080
   ```
   Затем откройте в браузере: `http://localhost:8080`
